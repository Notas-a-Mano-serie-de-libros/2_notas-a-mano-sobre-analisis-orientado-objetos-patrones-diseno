# Glosario

| Término | Definición breve |
| --- | --- |
| Abstracción | Representación de los rasgos esenciales de un concepto, omitiendo detalles que no son relevantes para el problema. |
| Acoplamiento | Grado de dependencia entre módulos, clases u objetos. |
| Cohesión | Grado en que las responsabilidades de un elemento están relacionadas entre sí. |
| Composición | Construcción de un objeto a partir de otros objetos con los que colabora. |
| Encapsulamiento | Protección del estado interno mediante una interfaz controlada. |
| Herencia | Mecanismo por el que un tipo adquiere características de otro. |
| Interfaz | Contrato que expresa operaciones disponibles sin imponer una implementación concreta. |
| Patrón de diseño | Solución reutilizable y contextual a un problema recurrente de diseño. |
| Polimorfismo | Capacidad de tratar objetos diferentes mediante un contrato común. |
| Responsabilidad | Obligación asignada a una clase u objeto dentro de una colaboración. |
