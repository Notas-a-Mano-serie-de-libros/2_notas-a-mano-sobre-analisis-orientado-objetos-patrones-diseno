# La obra

**Notas a mano sobre análisis orientado a objetos y patrones de diseño** presenta una ruta progresiva desde los mecanismos básicos del paradigma orientado a objetos hasta principios, buenas prácticas y patrones aplicables a problemas recurrentes de diseño.

## Propósito

La obra está dirigida a estudiantes, docentes y profesionales que necesitan comprender no solo la estructura de un patrón, sino el problema que lo motiva, sus participantes, consecuencias y límites de aplicación.

!!! info "Relación con el repositorio"
    El libro desarrolla la explicación completa. Este complemento facilita la navegación y enlaza las implementaciones Java para estudiar cada solución en funcionamiento.

## La portada

La guacamaya representa diversidad, adaptación y coordinación. Es una imagen coherente con el diseño orientado a objetos: componentes distintos conservan su identidad mientras colaboran dentro de una estructura común.
